- Fixed `GladiaSTTService` reconnecting on the Gladia Enterprise API (eu1, us1). A session URL's token is single-use there, so every reconnect was refused with "Token already used" and transcription stopped: a reconnect now opens a new session. The Enterprise API acknowledges no audio unless asked, so the buffer is no longer kept until acknowledged (a reconnect would have replayed the whole call); it keeps the audio since the last final, at most 15 s, which the new session hears again.
